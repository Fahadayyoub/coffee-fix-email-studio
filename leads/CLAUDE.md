# Leads folder rules

These rules apply only to files in `leads/`.

- **These are made-up practice people.** Everyone in `leads.csv` is invented for practice. None of them is a real customer.
- **Never add real people or real email addresses.** Not customers, not staff, not friends, not yourself.
- **Every row needs a consent value.** If a row has no value in the `consent` column, don't add it until it has one.
- **Never change the @example.com addresses.** Every email must end in `@example.com`. That domain is reserved and can never receive mail, so no real person is ever emailed.
