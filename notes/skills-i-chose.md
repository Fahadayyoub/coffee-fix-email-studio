# Skills I chose

Searched skills.sh on 15 November 2026. Searches: "email marketing", "email sequence", "campaign plan" and "resend". Nothing is installed yet.

## Use these

**1. Anthropic's marketing skills, for writing campaigns**
- Where: `anthropics/knowledge-work-plugins`, in the `marketing` folder.
- Skills: `campaign-plan` (3.4K installs) and `email-sequence` (3.1K installs). The same folder also has `draft-content` and `brand-review`.
- Why: Anthropic, the maker of Claude, publishes them. The repository has about 35,900 GitHub stars, was updated this week and uses an open license (Apache 2.0). They cover the planning and writing work this studio does.
- Note: these skills already come with the Marketing plugin in Claude, so we may not need to install anything.

**2. Resend's own skills, for sending email later**
- Where: `resend/resend-skills`.
- Skills: `resend` (24.7K installs) and `resend-cli` (14.1K installs).
- Why: Resend, the email service, publishes them. They match its tools exactly. The repository has about 210 stars, which is low, but the publisher is the company itself and it was updated this month (MIT license).
- Note: this studio writes drafts only. We would only need this if we choose to send through Resend one day.

## Avoid these

**1. `caffeinelabs/skills@extension-email-marketing`**
- It is the top result for "email marketing" with 31.7K installs, but its repository has only 2 GitHub stars.
- That many installs and almost no stars doesn't add up. It may be installed automatically by some other tool, or the count may be inflated. Either way, the number doesn't show real trust.

**2. The `mbfinotti` skills (for example `mbfinotti/sales-skills@sales-outbound-sequence`)**
- Each skill shows about 33K installs, but the repository has 3 stars and was only created in September 2026.
- Many different skills from this publisher show almost the same install count. That looks like inflated numbers, not real use. They are also aimed at cold sales emails, not our customers.

## How I decided

Check these three things before installing any skill:

1. **Who publishes it.** Prefer the company that makes the tool (Anthropic, Resend) or a well-known author. Check the name on GitHub, not only on skills.sh.
2. **Whether the GitHub repository looks trusted.** Look at its stars, how old it is and when it was last updated. Lots of installs with very few stars is a warning sign.
3. **What the skill actually does.** Open its SKILL.md and read it. Make sure it fits our work (planning and writing, not sending) and doesn't run anything you don't expect.
